# Java Coursework

A collection of weekly Java coursework and learning exercises.

## Repository structure

Each topic is stored in its own week-based directory:

```text
week-XX-topic/
├── README.md
├── solution/               # Student-written source files
└── teacher-provided-tests/ # Test harnesses and sample data supplied by the course
```
